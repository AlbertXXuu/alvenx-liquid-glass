# Task-local deployment research

These are preserved transport experiments from 21–22 October 2026, including rejected and failed attempts. They are **not library components, production dependencies, or a recommended deployment tool**. They did not change the product renderer, browser interactions, operating-system network settings or upstream Wrangler files.

Normal Wrangler publication was interrupted by API connection and upload failures. The experiments compare native/curl and HTTP/2 transports with fixed task-date endpoint candidates, bounded requests, normal HTTPS verification and existing Wrangler authentication. An observed send failure does not prove that no bytes reached the API. A source-package release does not establish a website deployment.

The API manifest gzip mode in v7–v9 is explicitly experimental; request encoding support was not assumed. v7 also encountered a disconnected-socket exception; v8 retains its correction. No outcome here certifies physical iOS or UI performance. Task-date fixed IPs are historical diagnostics, not future configuration advice.

The source hash index records actual preserved bytes. The v2 executed-source file is a reconstruction made by reversing the single later Expect-filter edit while retaining its CRLF bytes; it is labeled as reconstructed evidence, not a direct runtime snapshot. Raw child logs, credentials, tokens, API response bodies and personal local paths are excluded from this public archive. Sanitized attempt outcomes are recorded separately.

## Successful follow-up

The enabled Windows system proxy was not inherited by the earlier CLI environment (`proxy_used=0`). The unchanged v4 helper and same build completed API requests after receiving the existing proxy only through the child process environment; all 16 recorded requests show `proxy_used=1`. No system settings changed. `with_system_proxy.py` preserves the configuration-reading invocation without recording the actual proxy endpoint or credentials. See the final publication and deployment-proxy-resolution records. Earlier gzip and HTTP/2 experiments are retained as rejected research, not used by the successful deployment.
