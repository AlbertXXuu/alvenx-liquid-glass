# AlvenX Agent 工作区液态玻璃 1.5.0-agent.1

这一版本固定 `WorkspaceVolume` 的渲染、出芽、触摸和桌面鼠标响应。React 接入、样式和安装方式见 [Agent 接入指南](../../agent-integration.md)。独立预览消费与该源码配套的本地 tarball，保留 B 折射的原生文字层与字体恢复能力。

## 形体与光学

- 出芽时共用连续曲面。鞍点打开后，球与舱各自接收悬停、按压、拖动与回弹。刚分离的两侧各自保留过渡肩部，连接宽度继续收窄，避免切换成两个完全分离的原始形体时突然跳开。
- WebGL、SVG 回退与命中轮廓用同一组形变参数。轻点只产生短时压缩和回弹，拖动超过阈值后抑制误触。出芽时仍可拖动连接形体。尊重系统减少动效。
- 出芽阶段舱体浅层高度过渡只在舱体单独决定边缘时启用。在原先出现亮裂线的位置，向轮廓内侧推进一单位时，旧高度由 9.10 降至 2.87，恢复势场保护后由 18.74 升至 21.68。大球与宽舱也分别匹配了实际边缘坡度，压低内亮环和双边。
- Agent 舞台使用全幅背景。1440×900 桌面首屏球径约 403 CSS px，展开舱宽约 652 CSS px。窄屏纵向布置，390 CSS px 宽时球径约 195 CSS px。独立截图评审后补上开场提示、提高输入文字对比，并将动效选项收进单独的披露控件。

## 验证范围

同一 tarball 在独立 React 19 项目和隔离的 AlvenX Agent 中完成实际安装、类型检查和生产构建。几何回归涵盖横向和纵向分离，固定端点与残余连接下的独立轮廓，以及分离前后覆盖连续性。浏览器检查涵盖鼠标悬停、点击和拖动、出芽中按住跨过分离时刻、触摸拖动后再次轻点、键盘动效设置和原生输入。暂停背景动效时，另一侧的两块 WebGL 取样区域分别在鼠标拖动前后逐字节一致。

独立设计复核采用实际桌面和窄屏截图。首屏提示与球边缘留出独立间距，输入占位文字的截图取样对比约为桌面 5.58:1、窄屏 5.49:1。触摸验证来自 Chromium 设备模拟。

最终 Chromium 预览通过 48 项检查，未记录页面异常或本地 HTTP 错误。补查了五个出芽进度帧，涵盖连接态与分离初段。较宽的残余肩部继续使用平缓的高度过渡，随着肩部变窄逐步恢复浅舱材质，分离初段的细白条收回为柔和反光。
