# 1.2.0 — current public showcase

The owner authorized this revision for `https://alvenx.com/ui/` on **2026-10-19**, after implementation and screenshot/interaction self-review. It carries the R3 explicit-scene and touch-ownership work into the main showcase. The source and design remain **all rights reserved / UNLICENSED**; public visibility grants no open-source reuse license. Nothing is published to the npm registry.

## User-visible changes

- Canonical AlvenX glass navigation, with a native home button that returns the current page to its top while preserving its URL and state.
- A layered blue/indigo/violet background and a gradient **“Glass that follows your hand.”** headline. The large mother/connection/content form keeps its horizontal composition.
- A clearly named **Progress** demonstration starting at **50%**, with 0–100 numeric editing and a one-percent display step. Continuous pointer positions stay unrounded; the optical source and its displayed progress share that state.
- Transparent platform tap highlighting within `.alvenx-design`, targeting the grey switch pill and range rectangle reported on iPad. Authored press response, the actual contour focus path, native editing and text selection remain.
- The existing seven material parameters, saved settings, opacity default **0.3**, both blur ranges **0–6 px**, continuous B endpoint relation and release-only bounded return remain the material/input contract.

The showcase's registered SVG source is displayed both behind the lens and through its displacement filter. This is explicit-scene refraction, separate from arbitrary browser-backdrop refraction and from the large form's analytic 2.5D rendering. It is not a claim of arbitrary DOM capture, Safari backdrop-filter support or Apple's native renderer.

## Verification status and limits

The tap-highlight change has targeted local checks in Chromium and Windows Playwright WebKit at 393px and 1180px widths. They cover touch taps, mouse dragging, authored pressure response, keyboard contour focus and Latin/CJK field selection, with no page errors in those cases. Chromium reported zero-alpha tap highlighting on sampled kit controls while an outside button retained its platform default.

Apple documents a separate translucent tap overlay and zero alpha as its suppression mechanism. The physical iPad screenshot's shape and tap-only timing match that behavior. Windows WebKit cannot expose the iOS-specific property, so it cannot prove the reported overlay has disappeared on iPad. [Apple Safari CSS Reference](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariCSSRef/Articles/StandardCSSProperties.html)

The [prepublication verification](verification.json) records the completed type/docs, build, geometry/runtime, frozen-reference, installed-package and browser checks. Chromium and Windows WebKit each passed 85 assertions across 320, 393, 768, 1180 and 1366px widths, with no page errors. The [evidence manifest](evidence-manifest.json) identifies retained screenshot and result bytes. The native home button preserves actual saved material settings, URL, history, message and progress after click, Enter and Space; reduced-motion return is immediate. R3's performance measurements and exact-map comparisons remain identified as R3 evidence. A header/background/CSS revision is not a new latency or FPS benchmark.
