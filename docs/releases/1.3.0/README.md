# 1.3.0 — a single budding glass link

The owner clarified that the homepage entrance must grow as the existing mother–soft-neck–content-chamber family. Clicking the empty mother now grows the same continuous glass body to the right; its actual layout width pushes GitHub right. A native `explore me!` link is placed inside the grown chamber. ## Geometry and optics

`BuddingLink` reuses the existing volume coverage geometry, not its analytic environment renderer. `buddingGeometry` fits the sampled boundary with a periodic cubic B-spline. One shared path supplies actual browser-backdrop optics, normals, clipping, rim, shadow, focus and hit geometry through an opt-in `LiquidControl.contour` callback. There is no second glass surface, joining bridge, painted blue/violet layer or bitmap approximation.

The mother is left-anchored at 6px padding. Its diameter D scales the existing 300px logical mother; the chamber's height is 1.4D, with the existing allowed childX 1.15 width variation providing native-text inset. One progress value controls both the contour and occupied width. Time uses a 1150ms quintic smootherstep, with zero endpoint velocity/acceleration. The link fades into the chamber near the end and becomes interactive when growth completes. Native button and anchor are siblings inside one field surface.

The same existing clock handles frame cadence. Offscreen geometry pauses; re-entry completes any elapsed growth. Resting contours/maps remain cached. System reduced motion settles immediately. Pointer activation uses authored material feedback; compound keyboard focus uses the contour ring. Existing default control geometry and field focus behavior remain unchanged.

## Responsive host layout

The desktop action order remains Explore the work → growing glass → GitHub, with one continuous horizontal push. At widths ≤640px, the discovery pair is placed on its own row before interaction. This reserves enough room for the expanded body and prevents a mid-growth row jump. Header, headline, copy, primary CTA and page atmosphere keep their existing styles.
