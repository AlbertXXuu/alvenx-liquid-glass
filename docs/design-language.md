# AlvenX 设计语言

本文件描述用户于 2026-10-16 确认的 v6 视觉与交互基线，以及从该基线提取组件时需要保留的约束。它不把确认扩展为任意参数组合或全平台通过。实际基线和后续验收门槛见[确认记录](baseline-and-checklist.md)。产品 UI 与组件标签用英文；作者说明可用中文。

## 形体和材质

大形体是饱满、通透而有珠光体积的母体、短软膜颈和内容腔。出芽要能读出母体隆起、颈部伸展、子体生长与内容揭示，父子保持贴合。保留的是饱满／珠光效果，不强制一张固定圆形 PNG。不能把大外壳降成整页薄透明板，也不能恢复内容腔中央蝴蝶结状畸变。

小交互使用同一家族的柔软 C2 透镜轮廓。现有几何由周期三次 B 样条产生平滑曲线；不要用普通圆角矩形外边框替代当前轮廓。可见边缘、裁剪、法线图、焦点／选中描边和命中区域从同一帧的显示形体获得。变化中的外壳不能与静止命中框各走各的。

| 层级 | 当前实现与用途 | 不应据此宣称 |
| --- | --- | --- |
| 大母体／膜颈／内容腔 | 实时算法形体，WebGL 2.5D 高度／法线与环境近似；保留体积、珠光和连贯生长 | 对任意网页背景的真实屏幕空间折射，或 Apple 原生渲染 |
| 小玻璃控件 | 按当前显示轮廓，对真实浏览器背景作局部折射／模糊与光照 | 跨浏览器已等效、稳定 60fps，或只靠白描边就完成材质 |
| 前景文字与输入 | 普通可选择、可编辑 DOM，独立于光学层 | 将文字一起扭曲／模糊后仍算清晰阅读 |

默认态就应看到细腻透镜厚度与亮暗边，不能只在 hover 出现。高光依附当前轮廓和光源；禁止错形外圈、左侧向内漂的孤立白线，以及大面积突亮。箭头共用清晰的绘制规范，方向服从操作语义，不要求所有箭头朝同一方向。

## 颜色与背景

AlvenX 采用蓝 `#2563EB`、靛 `#4F46E5`、紫 `#7C3AED` 的品牌序列，`#93C5FD` 为辅助环境色。饱满形体和玻璃采样可以包含柔和灰蓝／灰紫层次，不能引入绿色、灰绿、薄荷绿或偏绿的阴影、状态色。

保留蓝紫色块的疏密、非均匀分布和可读的深浅层次。Background motion 开启时，几秒内能察觉平滑变化，不能变为闪烁或极淡均匀渐变。Reduced motion 优先停止或减少装饰运动，同时保留可操作性和清晰状态。正常视图不显示调试网格、贯穿背景曲线或文字安全框。

品牌网站的既有玻璃 token 是来源背景，不把其中旧 `18–24px` blur 等数值硬套到本基线；本包七参数以本文件表格为准。

## 状态与操作

| 状态 | 需要保留的行为 |
| --- | --- |
| Normal | 光学边缘可辨认，文字稳定；控件大小和可点击范围清楚 |
| Hover／近接 | 局部形变、折射和阴影联动，不能闪亮整块背景；目标可稳定获得 |
| Press | 从现有显示几何连续进入按下状态，保持 DOM 文本可读 |
| Drag | 透镜连续跟手，内部值不按显示精度或键盘 step 逐格跳动 |
| Overshoot | 两端可有额外阻尼视觉越界，有效数值始终 clamp 在范围内 |
| Release | 回到该端部几何锚点；不移动固定轨道来追随透镜 |
| Regrab | 从当前回弹位置继续抓取，不先跳回 rest 再开始拖动 |
| Focus | 键盘焦点沿相同轮廓可见；可访问名称、状态和错误可感知 |
| Reduced motion | 装饰运动静止或减弱，保留输入／切换功能，不依赖动画才能理解状态 |

所有交互家族都遵循上述原则，包括按钮、卡片、输入外壳、数字框、send、slider、switch。它不把卡片选择改成 switch；语义决定使用哪类控件。

## B 端部关系

轨道按静止透镜的 rest 几何向内收，固定其端帽。活动透镜在 hover、press 和拖动中根据**未舍入**的当前几何计算端部密切圆圆心，使局部端部与轨道端帽匹配。只要求局部曲率关系，不声称整个端部严格同心或全轮廓等距。

当前尺寸的实际 path 端部 gap 为 slider `15.53125px`、switch `8.65625px`；未舍入 helper 约 `15.54px／8.67px`，switch 静止总可见宽约 `74.234px`。这些是该尺寸的结果，不是固定 token；改宽、高、fullness 或轨道端帽半径必须重新推导。

额外软越界叠加于几何锚点，释放时清除该偏移，不改有效数值。switch 拖过中点立即改变 checked 状态；点击和键盘切换有可观察的连续位移，减少动效时可立即稳定。当前基线的重抓复测 offset `−3.152→−3.152` 为零跳位；尺寸变化后的行为需重新检查。

## 七参数与两个开关

以下默认值来自 v6 `DEFAULT_SETTINGS`，并非历史 v2 的设置。除用户明确要求的玻璃底色 `0.3` 外，其他默认是已确认小样的可调整工程基线，不能推断为永久最佳值。

| 英文标签／key | 含义 | 范围 | 首次／Reset 默认 | 手动提交／显示最多小数位 | slider 键盘步长 |
| --- | --- | --- | --- | --- | --- |
| Interaction strength / `interactionStrength` | 互动形变、折射与阴影反馈幅度 | 0–4× | 2.5 | 2 | 0.1 |
| Specular opacity / `specularOpacity` | 镜面高光可见权重 | 0–1 | 1 | 3 | 0.05 |
| Specular saturation / `specularSaturation` | 高光颜色饱和程度 | 0–3 | 2 | 2 | 0.1 |
| Refraction level / `refractionLevel` | 背景折射位移强度 | 0–3 | 2 | 2 | 0.1 |
| Blur level / `blurLevel` | 材质背景模糊量 | 0–6px | 2px | 1 | 0.1 |
| Progressive blur / `progressiveBlur` | 随表面位置变化的渐进模糊 | 0–6px | 2px | 1 | 0.1 |
| Glass background opacity / `glassOpacity` | 玻璃底色不透明度，不是文字透明度 | 0–1 | 0.3 | 3 | 0.001 |

`Background motion` 对应 `ambient`，默认 `true`；`Reduced motion` 对应 `reducedMotion`，默认 `false`。系统减少动效偏好仍约束最终行为，不能仅因为保存值为 false 就强行播放。

两项 opacity 的数学值域完整保持 0–1，不扩大到 1 以上。两种模糊按用户纠正保留 0–6px。高范围必须实际作用到渲染器；不能 UI 显示 3、内部仍偷偷截为 2。大形体与小控件实现不同，分别验证其真实参数与效果。

## 直接输入、键盘与存储

数字框使用清晰 DOM 的 `type=text`、`role=spinbutton`、`inputmode=decimal`，提供 aria 范围、有效值、错误和说明。手动草稿支持小数及中间编辑态，提交时才规范化。

1. Enter 或 blur 完整解析为有限数值，归到最近的 `[min,max]` 边界，再按表格精度四舍五入；显示与保存同步。超限或过精度给简短可见提示。
2. `.3`、`1.`、合法指数 `3e-1` 可提交；格式化为普通小数。全宽数字、点与正负号先转 ASCII。单位、多点、NaN、Infinity、`0x` 等无效内容拒绝。
3. 空、未完成或非法输入恢复最近已提交值，不能恢复成默认值。Escape 取消。draft 最多 32 字符；过长粘贴整体拒绝，不截成另一个有效数字。
4. 保留选区、Ctrl+A、文本编辑、粘贴与撤销。IME 组合期间 Enter、Escape 和方向键交给输入法；不抢走组合事件。
5. 数字框普通 Up／Down 按最小显示单位调值：2 位为 0.01、3 位为 0.001、1 位为 0.1。无修饰键的 Home／End 到边界。slider 使用表格中的粗步长，PageUp／PageDown 为 10 步；指针拖动仍为连续值。
6. 未改动草稿即失焦，保留原始浮点和旧保存值，不能按显示小数位量化。Reset 在编辑期间必须最终胜出，旧 draft 的 blur 不能把它覆盖。

旧小样使用 `alvenx-material-direction-v2` 作为存储 key，后续版本没有通过改 key 强制覆盖偏好。移植到别的产品时选用宿主自己的 key；保留有效有限数值和布尔值，缺失字段使用默认值，越界数值归界，损坏存储可回退默认。不要为了“更新默认”清空合法保存值。存储不可用时界面仍须可操作。

## 字体、品牌与清晰文本

Instrument Sans 用于 Latin／数字，MiSans 用于中文，按 `"Instrument Sans", "MiSans", sans-serif` 排列。使用正式 AlvenX 字标／AX 轮廓资产，不用普通文字重做标志。字体和品牌替换点见[移植指南](integration.md)，许可见[来源说明](attribution.md)。

品牌正文通常 14–16px，辅助文字至少 12px，输入 14px／1.55；阅读行高可从 1.62 开始。中文长文需单独检查，不能照搬紧凑英文标题行高。v6 的小提示存在更紧凑字号，这是当前小样事实，不把它推广成所有错误提示的可读性标准。

文字只在几何安全区内排版，不随折射扭曲或随按压拉伸。内距应随实际形体、尺寸和正文长度检验；当前展示布局不等于任意长文自动排版引擎。检查首尾行、焦点、选区、长数字和中文全宽 `？／`，不能靠可见安全框掩盖裁剪问题。

验证字体须同时检查资源成功加载与实际字形来源；`document.fonts.check()` 单独不能证明 CJK 真实用了 MiSans。新消费项目的字体、缩放和长文本检查仍需完成。
