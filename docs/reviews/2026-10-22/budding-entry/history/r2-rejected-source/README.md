# Budding entrance refinement review

Owner request, 2026-10-22: separate the mother and text chamber a little farther, narrow their connection, add room to the right of the label and make the glass look less flat. This isolated review compares the unchanged production BuddingLink with one proposed contour and lighting treatment. It does not change the homepage dependency or library defaults.

Run `npm run dev` and open `/showcase/budding-refinement-review/index.html`. The Vite multi-page build includes this entry. Hosted review target: `https://alvenx.com/ui/budding-refinement-review-20261022/`.

- `geometry.ts` reuses the accepted volume coverage samples and reconstructs a periodic uniform cubic B-spline, retaining C2 joins. At full growth the chamber moves approximately 0.24 mother diameters farther right, and its right contour receives up to 0.12 diameters extra room. The sampled local neck half-height is reduced by up to 34% before spline reconstruction; this is the construction parameter, not a claim of an exact 34% reduction in the final spline's minimum thickness.
- `main.tsx` preserves the existing LiquidControl optical body and derives its clip, normal map, rim and hit path from that contour. Color continues to come from the actual backdrop rather than a painted blue/violet fill. The proposal's label has an additional 0.16-diameter right inset.
- `volume-light.ts` replaces R1's blurred-alpha specular filter, which left a plateau through the interior and mostly lit the rim. R2 samples the current C2 boundary and constructs full circular depth cross-sections: `z = 0.88 sqrt(r(x)^2 - (y - centreY(x))^2)`. Finite differences supply continuously varying interior normals for a broad white softbox reflection and weaker focused highlight. The mother has a dome, the right chamber has a convex shoulder and the narrowed neck has lower depth. Only transparent achromatic reflection and weak neutral attenuation are overlaid; neutral attenuation is capped at 0.095 alpha before edge coverage and the layer's CSS opacity. The separate contact shadow remains weak. These are a 2.5D lighting approximation over the existing real-backdrop refraction, not a new physically unified 3D renderer.
- Lighting buffers and the 2D context are prepared when the visible review component mounts. A fixed 1.5x CSS-resolution map is independent of device pixel ratio: 295 x 135 = 39,825 pixels for the current 54 px proposal. ImageData, depth and column buffers are reused; growth never resizes the canvas, no PNG encoding is used, and identical paths reuse the retained image. Drawing follows the existing contour/clock callback, with no additional animation loop; the resting component sleeps. This is a bound for this isolated proposal, not evidence of physical phone power use or whole-page frame rate.
- `review.css` supplies the comparison layout and a homepage-like blue/violet environment. Both examples use the real 54 px mother size; the proposed expanded occupied width is about 194 px versus 175 px. Actual occupied width moves the adjacent GitHub link.

Activate each empty mother with pointer, touch or Enter/Space, then use the revealed native link. Reset restores both examples. The lighting toggle isolates the volume cue. Reduced motion reveals the final state immediately. Review screenshots and browser checks are retained with the navigation-unification publication records; desktop browser testing does not certify physical iOS/Combo Touch behavior or mobile power use. Owner visual acceptance precedes any change to the production homepage.
