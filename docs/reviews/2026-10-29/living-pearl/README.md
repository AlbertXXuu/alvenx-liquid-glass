# Living pearl showcase — 2026-10-29

The owner requested softer blue-violet living colour and more legible hover/press response for the small sphere and oval, presented on `/ui/`. The reference images were described by the parent task after direct cloud-side pixel inspection; they were not locally available. The existing large volume already samples a moving analytic environment, so this change adds a dedicated small interactive specimen below that volume. The sphere grows into a detached chamber; its label links to the refraction section. The mother and chamber use the accepted C2 family, independent pointer lighting, bounded pull and spring return. Default material remains pale blue/lavender with dark readable foreground; no floating tint overlay was introduced.

The small canvas advances the existing analytic environment only while visible, Background motion is enabled and reduced motion is inactive. It reuses the shared clock, updates at about 12.5 Hz rather than rebuilding local optical maps per frame, and stops when offscreen or hidden. Reduced-motion press uses an immediate subtle fill and keyboard focus has a visible contour. Native English and Chinese labels are retained.

Evidence: local 24 interaction, 9 touch/locale and 6 lifecycle checks; built 24 + 9; online 24 + 9, all passed. The 21 prior autoplay checks and library check/build/contract/runtime passed. First-frame comparison at phase zero had zero differing sampled channels for 44/54px. The online comparison over ~6.5s measured average absolute differences about 1.6–2.2/255 in selected mother/chamber red and green channels (peak 5/255); see `online-pixel-difference.json` and paired screenshots. The selected regions exclude text. The same-device Chromium benchmark: old static small canvas 0 redraws over 5s; new ambient-on sample 60 redraws/5s at a reported mean CPU submission duration 0.057ms, both 42,504 raster pixels. This is not GPU time, whole-page cost, stable FPS, battery or phone performance.
